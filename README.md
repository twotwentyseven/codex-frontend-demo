# Getting Started with Codex Frontend Demo

## Project Overview
Codex Frontend Demo is a project for testing/demoing Frontend codex coponents. The project uses Vite as the build tool.

## Prerequisites
- Node.js (Latest LTS version recommended)
- npm
- Git

## Tech Stack
- Vite for build tooling

## Project Setup

1. Clone the repository:
```bash
git clone [repository-url]
cd codex-frontend-demo
```

2. Install dependencies:
```bash
npm install
```

3. Environment Setup:

### Running the Development Server
```bash
npm run dev
```

## Trying to test a local version?

run this command in your broswer console, you will have to make the file name match the folder you have cloned the project into. The folder will also need to be set up to use valet.

```bash
Codex().store('scriptUrl', 'https://codex-frontend.test/dist/main.js');
```
